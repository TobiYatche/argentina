# argentina

Простые утилиты для работы с административными и географическими данными Аргентины.

Если вы работаете с аргентинскими базами данных, рано или поздно появляются DNI с точками, провинции, записанные пятью разными способами, CBU, CUIT, противоречивые адреса и странные почтовые индексы. Этот пакет пытается избавить вас от этой рутины, не отнимая всё утро.

## Установка

```bash
pip install argentina
```

Опциональные extras:

```bash
pip install "argentina[geo]"
pip install "argentina[economia]"
pip install "argentina[data]"
```

См. [Опциональные extras](../../extras.md) для полной таблицы (`maps`, `feriados`, `georef`, `elecciones` и др.).

## Рекомендуемый импорт

```python
import argentina as arg
```

Документация и примеры используют `import argentina as arg`, потому что это сохраняет сниппеты короткими и согласованными. Сниппет, скопированный из любой части проекта, работает как есть.

Также можно импортировать конкретные модули, если нужен только один:

```python
from argentina import provincias
import argentina.economia as economia
```

## Быстрое использование

```python
import argentina as arg

arg.provincias.lookup("PBA")
arg.personas.limpiar_dni("12.345.678")
arg.postal.validar_cpa("C1425ABC")
arg.bancos.validar_cbu(
    "2850590940090418135201"
)
```

## Лёгкое ядро

Базовый пакет старается оставаться лёгким. `import argentina` стартует за ~70 мс и **не** импортирует автоматически:

- `pandas`
- `geopandas`
- `requests`
- `duckdb`
- `pyarrow`
- `folium`

Более тяжёлые функции устанавливаются как **опциональные extras**, а их зависимости импортируются отложенно — только когда вы вызываете нужную функцию.

## Философия

- **Лёгкое ядро** — `import argentina` не подгружает pandas и ничего тяжёлого.
- **Модульность** — каждый модуль решает одну задачу и используется отдельно.
- **Маленькие данные встроены, большие тянутся по запросу** — провинции и департаменты встроены; шейпы IGN и EPH скачиваются и кешируются в `~/.cache/argentina/` при первом обращении.
- **Прозрачно о том, что приблизительно** — нечёткие совпадения, синтаксические валидации и неполные данные документируются как таковые.
- **Никакого скрейпинга и персональных данных** — только официальные публичные API (INDEC, IGN, BCRA, Georef, datos.gob.ar).

> Цель — не переизобретать pandas или geopandas. Цель — решать частые аргентинские задачи через простой и согласованный API.

Подробнее в [docs/filosofia.md](../../filosofia.md).

## Статус

- **Версия:** 0.3.0 (Beta).
- **Python:** 3.9+.
- **Источники:** INDEC (Censo 2022, EPH, экономические ряды), IGN (картография и Argenmap), BCRA, datos.gob.ar (Georef), argentinadatos.com (праздники).
- **Тесты:** 550 автоматических тестов (все проходят на 2026-05-13).
- **Целевая аудитория:** исследования, анализ данных, консалтинг, государственный сектор и частные проекты, работающие с административными данными Аргентины.
